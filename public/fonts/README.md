# Summer Loving Sans Font Placement

Place your Summer Loving Sans font files in this folder with any of the following names:
- `SummerLovingSans.woff2`
- `SummerLovingSans.woff`
- `SummerLovingSans.ttf`

The project is already pre-configured to automatically load these files via `@font-face` in `src/app/globals.css`, or use locally installed fonts if available on your system, with high-quality geometric sans fallback typography.
